4. Should DigitalProduct skip the stock rule?
Prediction: No. Under LSP a child class must be usable anywhere the parent is used, so it cannot weaken the rules of Product. If Product promises stock is never negative then DigitalProduct must keep that promise, otherwise code that trusts Product would break when given a DigitalProduct. That is why the check is in Product's __init__ and update_stock(), so both children inherit it.
